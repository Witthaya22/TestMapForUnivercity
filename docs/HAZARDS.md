# HAZARDS.md — ระบบจุดอันตรายและการแจ้งเตือน

เดินไปเรื่อย ๆ ปักจุดที่อันตรายไว้ แล้วแอปจะ **เตือนล่วงหน้า** ตอนมีคนเดินเข้าใกล้
ทั้ง **ข้อความบนจอ**, **เสียงเตือน** และ **เสียงพูดภาษาไทย** — ทำงานออฟไลน์ 100% เหมือนส่วนอื่นของแอป

> เข้าใช้งาน: **ตั้งค่า → การเตือนจุดอันตราย → ปักและจัดการจุดอันตราย**
> เปิด/ปิดการเตือนและเสียง: **ตั้งค่า → การเตือนจุดอันตราย**
> โค้ด: `ui/hazard/` · `navigation/HazardMonitor.kt` · `core/speech/SpeechAnnouncer.kt` · `core/sound/HazardSoundPlayer.kt`

---

## 1. จุดอันตราย ≠ POI ≠ จุดพิกัด GPS

ตอนนี้แอปมี 3 ระบบที่ "ปักจุด" และตั้งใจแยกกันทั้งหมด **อย่ารวม**

| | POI (`ui/survey/`) | จุดพิกัด GPS (`ui/gpslog/`) | **จุดอันตราย (`ui/hazard/`)** |
|---|---|---|---|
| ตอบคำถามว่า | "ที่นี่คืออะไร จะไปยังไง" | "เครื่องวัดได้เท่าไร แม่นแค่ไหน" | **"ตรงนี้อันตราย ต้องบอกก่อนถึง"** |
| มีรัศมีไหม | ไม่มี | ไม่มี | **มี** — เป็นหัวใจของระบบ |
| เข้ากราฟ routing | เข้า (เป็นจุดหมาย) | ไม่เข้า | **ไม่เข้า** |
| ตารางใน Room | `poi` | `gps_point` | `hazard_point` |
| ไฟล์ export | `pois_surveyed.geojson` | `gps_points_*.geojson/.csv` | `hazards.geojson` |

**ทำไมต้องมีรัศมี:** ทางข้ามที่รถเร็วคืออันตรายยาว 30 เมตร แต่ฝาท่อหายคืออันตรายกว้าง 1 เมตร
ถ้าเตือนที่ระยะผิด จะแย่กว่าไม่เตือน — เตือนเร็วไปคนก็เลิกสนใจ เตือนช้าไปก็ไม่ทัน

## 2. วิธีปักจุด

1. **เดินไปยืนตรงจุดนั้นจริง ๆ** แล้วกด **"ปักจุดอันตรายตรงนี้"**
   พิกัดจะมาจากเครื่องรับตัวเดียวกับที่จะใช้ตัดสินใจเตือนทีหลัง offset จึงหักล้างกัน
   (เหตุผลเดียวกับ `ACCURACY.md` A1) และระบบจะจำค่าความคลาดเคลื่อนตอนปักไว้ด้วย
2. จุดที่ยืนไม่ได้ (กลางถนน / หลังรั้ว) ให้ **กดค้างบนแผนที่** — จะบันทึกว่าไม่ได้วัดด้วย GPS
   และหน้ารายละเอียดจะบอกไว้ตรง ๆ ว่าเป็นการกะเอา
3. เลือก **ประเภท** และ **ระดับความอันตราย** แล้วลาก **ขอบเขต**
   วงกลมบนแผนที่คือ **ระยะที่แอปจะเริ่มพูด** ไม่ใช่แค่ขนาดของอันตราย — ดูแล้วปรับให้คลุมพอดี
4. ใส่รายละเอียดสั้น ๆ เช่น "หมา 3 ตัวเฝ้ารถอยู่หน้าโรงอาหาร" — ข้อความนี้จะถูกพูดออกเสียงด้วย
5. เลือก **เสียงเตือน** ที่จะดังนำก่อนคำพูด (ดู §6) ค่าเริ่มต้นคือเสียงตามระดับความอันตราย
   กด **"ลองฟัง"** ก่อนเสมอ เสียงที่เลือกในห้องเงียบยังไม่มีใครพิสูจน์ว่าได้ยินตอนยืนริมถนน

### ประเภทที่มี (`HazardType`)

`dog` สุนัข · `traffic` รถ/ทางข้าม · `flood` น้ำท่วมขัง/พื้นลื่น · `dark` ไม่มีไฟ ·
`construction` ก่อสร้าง · `broken_path` ทางชำรุด/หลุม · `animal` งู/แมลง · `other` อื่น ๆ

รายการนี้ **สั้นและปิด** โดยตั้งใจ คนที่กำลังเดินมีเวลาราว 2 วินาทีในการตอบสนองต่อคำเตือน
ประเภทจึงต้องเป็นคำที่เข้าใจทันที ถ้าเปิดให้พิมพ์เองจะได้คำเตือนที่ไม่มีใครทันตีความ

### ปิดการเตือน ≠ ลบ

ก่อสร้างเสร็จแล้ว / ซ่อมฝาท่อแล้ว → กด **"ปิดการเตือน"** จุดจะจางอยู่บนแผนที่เป็นประวัติ
**ลบ** ไว้ใช้เฉพาะตอนปักผิดเท่านั้น เพราะ "เคยมีหลุมตรงนี้" มีค่าเมื่อมันกลับมาอีก

## 3. กติกาการเตือน (`navigation/HazardMonitor.kt`)

### ระยะที่เริ่มเตือน

```
ระยะเตือน = ขอบเขตที่ตั้งไว้ + ระยะเผื่อตามระดับความอันตราย
```

| ระดับ | ระยะเผื่อ | ตัวอย่าง (ขอบเขต 15 ม.) | พูดซ้ำไหม |
|---|---|---|---|
| `caution` ควรระวัง | +10 ม. | เตือนที่ 25 ม. | ไม่ |
| `warning` อันตราย | +20 ม. | เตือนที่ 35 ม. | ไม่ |
| `danger` อันตรายมาก | +35 ม. | เตือนที่ 50 ม. | ซ้ำทุก 60 วินาทีถ้ายังอยู่ |

ระดับความอันตรายซื้อ **ระยะ** ไม่ใช่ความดัง — บอกว่ามีหมาดุตอนเดินถึงตัวแล้ว ไม่นับเป็นการเตือน
คนเดินเร็วราว 1.3 ม./วินาที ดังนั้น 35 เมตรคือเวลาคิดประมาณ 27 วินาที

### กันการเตือนรัว (สำคัญมาก)

- เตือน **ครั้งเดียว** ตอนเข้าเขต ไม่ใช่ทุก fix (ไม่งั้นเดินผ่านทางข้ามเดียวจะพูด 30 รอบ)
- จะเตือนซ้ำได้ก็ต่อเมื่อ **เดินออกไปไกลกว่าระยะเตือน + 15 ม.** แล้วกลับเข้ามาใหม่
  ระยะเผื่อ 15 ม. นี้กว้างกว่าการแกว่งของ fix ที่ดี จึงยืนคร่อมขอบเขตแล้วไม่พูดรัว
- เตือนพร้อมกันหลายจุด → **พูดแค่จุดที่ร้ายแรงที่สุด** ที่เหลือขึ้นเป็นตัวเลขบนแบนเนอร์

> เหตุผลที่ต้องเข้มเรื่องนี้: ระบบที่เตือนบ่อยเกินไปจะโดนปิดเสียงทิ้ง แล้วหลังจากนั้น
> มันจะไม่เตือนใครเรื่องอะไรอีกเลย ซึ่งแย่กว่าไม่มีระบบตั้งแต่แรก

### ไม่เอาความคลาดเคลื่อน GPS มาขยายรัศมี

จงใจไม่ทำ เพราะถ้าสัญญาณแย่แล้วขยายรัศมีตาม จะเตือนจุดที่คนอยู่ห่างเป็นสิบเมตร
อีกอย่าง fix ที่มาถึงตรงนี้ผ่านด่านความแม่นยำ 25 ม. ของแอปมาแล้ว (`ACCURACY.md` A4)

## 4. การเตือนมี 3 แบบ ใช้คนละหน้าที่

| แบบ | เมื่อไร | ทำไมต้องมี |
|---|---|---|
| **แบนเนอร์** บนแผนที่ | ตลอดเวลาที่ยังอยู่ในเขตอันตราย | คำเตือนต้อง "ทนต่อการถูกมองข้าม" — เหลือบดูแล้วเดินต่อ พอหันกลับมามันยังอยู่ |
| **เสียงเตือน** | นำหน้าเสียงพูดทุกครั้งที่พูด | ดังทันที ไม่ต้องรอสังเคราะห์เสียง ทะลุเสียงรถได้ และยังเตือนได้ในเครื่องที่ไม่มีเสียงพูดไทย |
| **เสียงพูด** | ตอนเข้าเขต (และซ้ำถ้า `danger`) | คนที่กำลังมองถนนอยู่ อ่านจอไม่ได้ ซึ่งเป็นสถานการณ์ที่ต้องเตือนที่สุดพอดี |
| **Dialog** | เฉพาะ `danger` และเฉพาะครั้งแรกที่เข้า | Dialog บังแผนที่ตอนคนกำลังเดินก็เป็นอันตรายย่อม ๆ จึงเก็บไว้ใช้กับกรณีที่ "ควรหยุดอ่าน" จริง ๆ |

**เตือนล่วงหน้าตอนวางเส้นทาง:** พอเลือกจุดหมายแล้ว แถบวางแผนเส้นทางจะบอกว่า
เส้นทางนี้ผ่านจุดอันตรายกี่จุด อะไรบ้าง ห่างจากจุดเริ่มเท่าไร (เรียงตามลำดับที่จะเจอ)
เพื่อให้ตัดสินใจเลี่ยงได้ตั้งแต่ยังไม่ออกเดิน ไม่ใช่ไปรู้เอาตอนยืนอยู่ริมถนนแล้ว

## 5. เสียงพูดภาษาไทย (`core/speech/SpeechAnnouncer.kt`)

ใช้ `android.speech.tts.TextToSpeech` ซึ่งเป็นของ AOSP **สังเคราะห์เสียงในเครื่อง**
ไม่ต้องต่อเน็ต ไม่มีค่าใช้จ่าย ไม่มี API key และไม่มีเสียงใดถูกส่งออกจากเครื่อง

- ผูก engine **ตอนจะพูดครั้งแรกเท่านั้น** ใครไม่เปิดเสียงเตือนก็ไม่มีการเปิด service เลย
- ผูกแล้วไม่ปิดจนกว่าโปรเซสจะตาย (เหตุผลเดียวกับ `LocalTileServer`) เพราะถ้าปิด ๆ เปิด ๆ
  คำเตือนครั้งถัดไปจะช้าไป 1 วินาที ซึ่งสำหรับคำเตือนคือเสียคุณค่าไปทั้งหมด
- ตั้ง `USAGE_ASSISTANCE_NAVIGATION_GUIDANCE` → เพลงที่ฟังอยู่จะ**หรี่ลง** ไม่ใช่หยุด
- ความเร็วเสียง 0.95 ช้ากว่าปกตินิดหน่อย เพราะเป็นประโยคที่ได้ยินครั้งเดียว กลางแจ้ง ข้างถนน

**ถ้าเครื่องไม่มีเสียงไทย** (เจอบ่อยในเครื่องราคาประหยัด) จะตรวจพบตอน init แล้ว
เตือนเป็นข้อความอย่างเดียว พร้อมขึ้น snackbar บอกครั้งเดียวว่าให้ไปติดตั้งเสียงไทยในตั้งค่าระบบ
**ห้ามทำให้เงียบเฉย ๆ โดยไม่บอก** ไม่งั้นผู้ใช้จะนึกว่าระบบเตือนพัง

### ข้อความที่พูดต่างจากที่แสดงบนจอเล็กน้อย

อยู่ในไฟล์เดียวกัน (`ui/common/HazardWording.kt`) เพราะสองอย่างนี้ต้องสอดคล้องกัน
และวิธีที่มันจะเพี้ยนออกจากกันคือมีคนไปแก้อันเดียว

- บนจอ: ระยะละเอียดถึงหลักเมตร
- เสียง: **ปัดเป็นช่วง 5 เมตร** เพราะพูดออกมาเป็นเลขละเอียดจะฟังดูแม่นเกินจริง
  และกว่าจะพูดจบคนก็เดินไปแล้ว ส่วนการเตือนซ้ำจะ **ตัดตัวเลขทิ้ง** เพราะคนที่ยังอยู่ในเขต
  ไม่ได้ต้องการให้วัดระยะให้

## 6. เสียงเตือน (`core/sound/HazardSoundPlayer.kt`)

**เสียงมาก่อน แล้วค่อยพูด** ไม่ใช่พร้อมกัน เพราะสองอย่างนี้บอกคนละเรื่อง
ถ้าซ้อนกันจะไม่ได้ทั้งคู่ เสียงมาก่อนเพราะมันมาถึงเร็วที่สุด — ไม่ต้องรอ TTS สังเคราะห์
ดังทะลุเสียงรถ และเข้าใจได้ก่อนคำแรกจะออก ส่วนประโยคที่ตามมาค่อยบอกว่าอันตรายอะไร ห่างเท่าไร

> **เสียงดังตอนเดียวกับที่พูดเป๊ะ ๆ** ไม่มีเงื่อนไขของตัวเอง ใช้กติกาเดียวกับ §3 ทุกข้อ
> ถ้าทำให้เสียงดังบ่อยกว่าที่พูด = ระบบเตือนทั้งระบบจะโดนปิด (เหตุผลเดียวกับ §3)

### เสียงที่มีให้ 2 เสียง

| id | เสียง | ใช้กับระดับ |
|---|---|---|
| `bundled:chime` | สองจังหวะ เบา (A5 → E6) ~0.35 วิ | `caution` · `warning` |
| `bundled:alert` | สามจังหวะ ด่วน (1.6 kHz) ~0.37 วิ | `danger` |

สองเสียงนี้ **สังเคราะห์เองด้วย `tools/make_alert_sounds.py`** ไม่ได้โหลดมาจากไหน
จึงไม่มีเรื่องลิขสิทธิ์ต้องตาม และถ้าออกไปฟังกลางแจ้งแล้วไม่เหมาะ ให้แก้ตัวเลขในสคริปต์แล้ว gen ใหม่

```bash
python3 tools/make_alert_sounds.py   # เขียนทับ app/src/main/res/raw/hazard_*.wav
```

**ระดับความอันตรายเลือกเสียงให้เอง** เพื่อให้เสียงบอกข้อมูลชุดเดียวกับระยะเตือน
คนที่เคยได้ยินทั้งสองเสียงจะแยกออกว่าอันไหน "เดินเลี่ยง" อันไหน "หยุด" ตั้งแต่ก่อนประโยคจะเริ่ม

### เพิ่มเสียงของตัวเอง มี 2 ทาง เลือกตามว่าใครต้องได้ยิน

| | **วางไฟล์ใน `assets/sounds/`** | **นำเข้าจากในแอป** |
|---|---|---|
| ทำตอนไหน | ก่อน build | ตอนใช้งานจริง ในหน้าปักจุด |
| อยู่ที่ไหน | **ในตัว APK** | เครื่องใครเครื่องมัน |
| ใครได้ยิน | **ทุกคนที่ลงแอปนี้** | เฉพาะคนที่นำเข้าเอง |
| แชร์ `hazards.geojson` แล้วเสียงติดไปไหม | **ติดไป** | ไม่ติด → ตกกลับไปใช้เสียงตามระดับ |
| id ที่เก็บ | `asset:siren.mp3` | `sound_<uuid>` |

### ทาง A — วางไฟล์ mp3 ลงใน `assets/sounds/` (แนะนำ ถ้าอยากให้ทุกคนได้ยินเหมือนกัน)

```
app/src/main/assets/sounds/
├── siren.mp3            → ขึ้นในรายการเลือกเสียง ชื่อ "siren"
└── default_danger.mp3   → กลายเป็นเสียงเริ่มต้นของ danger ทุกจุด
```

**วางไฟล์ แล้ว build ใหม่ จบ ไม่ต้องแก้โค้ดสักบรรทัด** แอปอ่านรายชื่อไฟล์ในโฟลเดอร์นี้ตอนรัน

**นามสกุลที่รับ:** `.mp3` `.ogg` `.wav` `.m4a` `.aac` `.opus` — จำกัดเท่านี้เพราะ Android
ไม่บีบอัดไฟล์พวกนี้ตอนแพ็กลง APK แอปจึงเปิดด้วย `openFd` ได้ ไฟล์อื่น (เช่น `.txt`, `README.md`)
**ถูกข้ามเงียบ ๆ** ดีกว่าเอามาโชว์แล้วกดเล่นไม่ออกตอนยืนอยู่ริมถนน

**ชื่อพิเศษ — แทนเสียงเริ่มต้นไปเลย:** ถ้ามีไฟล์ชื่อ `default_caution.*` / `default_warning.*` /
`default_danger.*` ไฟล์นั้นจะกลายเป็นเสียงเริ่มต้นของระดับนั้นแทนเสียงที่ gen มา
จุดที่คนปักไม่ได้เลือกเสียงเอง (ซึ่งคือจุดส่วนใหญ่) จะเปลี่ยนทั้งระบบทันที ไม่ต้องตั้งค่าอะไร

> ไฟล์ในโฟลเดอร์นี้ **ไม่มีลิมิตความยาวบังคับ** ต่างจากไฟล์ที่นำเข้าในแอป เพราะเป็นของที่
> คนทำแอปใส่เอง — แต่ควรสั้น 2–3 วินาที เพราะมันดัง**นำหน้า**ประโยคที่บอกว่าอันตรายอะไรอยู่กี่เมตร

รายละเอียดอยู่ใน `app/src/main/assets/sounds/README.md` ข้าง ๆ ไฟล์เลย

### ทาง B — นำเข้าเสียงเอง

ในหน้าปักจุด → ช่อง **"เสียงเตือน"** → **"นำเข้าเสียงจากเครื่อง"** (เลือกไฟล์ `audio/*`)

ไฟล์จะถูก **คัดลอกเข้ามาเก็บใน `filesDir/hazard_sounds/`** ไม่ใช่จำ URI ไว้เฉย ๆ
เพราะ URI ที่ได้จากตัวเลือกไฟล์เป็นของยืม หายได้ตอนรีบูตหรือตอนผู้ใช้ลบไฟล์ใน Downloads
และเสียงเตือนที่หายไปเงียบ ๆ คือความล้มเหลวที่แอปนี้รับไม่ได้ อีกอย่างคัดลอกแล้วก็ออฟไลน์ครบ

**เงื่อนไขที่รับ** (อยู่ที่ `data/repository/HazardSoundRepository.kt`):

| กติกา | ค่า | เหตุผล |
|---|---|---|
| ขนาด | ≤ 2 MB | เผื่อไว้เกินพอสำหรับเสียงเตือน แต่กันไฟล์เพลงที่เผลอเลือกมา |
| ความยาว | ≤ 5 วินาที | เสียงดัง **นำหน้า** ประโยค ถ้ายาวกว่านี้คำเตือนจะมาไม่ทัน |
| ถอดรหัสได้ | ต้องได้ | ตรวจด้วย `MediaMetadataRetriever` ของเครื่องนั้นเอง ไม่เดาจากนามสกุลไฟล์ |

ตรวจ**หลัง**คัดลอกเสร็จ เพราะเครื่องเดียวที่ตอบได้ว่าไฟล์นี้เล่นได้ไหมคือเครื่องที่จะเล่นมัน
ถ้าไม่ผ่านจะลบไฟล์ที่คัดลอกมาทิ้ง ไม่เหลือขยะไว้

### ลบเสียงที่นำเข้า

จุดที่เคยใช้เสียงนั้น **ไม่ถูกแก้** ยังเตือนต่อโดยใช้เสียงตามระดับความอันตราย
ถ้าไปไล่เขียนทับ `soundId` ของทุกจุด = ทางเดียวที่ทำให้สิ่งที่ผู้ใช้เลือกไว้หายถาวร

**ลบได้เฉพาะเสียงที่นำเข้าจากในแอป** เสียงที่ gen มา 2 ตัวและไฟล์ใน `assets/sounds/`
เป็นส่วนหนึ่งของ build ลบจากในแอปไม่ได้ (ถ้าจะเอาออกคือลบไฟล์แล้ว build ใหม่)
เพราะสถานะ "ทั้งมอไม่มีเสียงเตือนเหลือเลย" ไม่ควรไปถึง

### ปิดเสียงได้ที่ไหน

**ตั้งค่า → การเตือนจุดอันตราย → "ส่งเสียงเตือนก่อนพูด"** — แยกสวิตช์จากเสียงพูด
เพราะสองอย่างนี้พังคนละแบบ เสียงเตือนคือครึ่งที่ยังทำงานในเครื่องที่ไม่มีเสียงพูดภาษาไทย
คนที่ปิดเสียงพูดมักอยากให้ยังเตือนอยู่ ไม่ได้อยากเดินแบบเงียบสนิท

## 7. ไฟล์ `hazards.geojson`

`FeatureCollection` ของ `Point` ตาม RFC 7946 — ใช้ **schema แบบเดียวกับ POI**
(คีย์ camelCase, เวลาเป็น epoch milliseconds) เพราะเป็นข้อมูลที่คนแก้และ merge กัน
ไม่ใช่ค่าที่วัดได้แบบไฟล์ GPS log

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": { "type": "Point", "coordinates": [101.3529617, 14.1610243] },
      "properties": {
        "id": "hazard_8f3c...",
        "type": "dog",
        "severity": "danger",
        "radiusMeters": 25.0,
        "description": "หมาเฝ้าอยู่ 3 ตัว",
        "isActive": true,
        "soundId": "bundled:alert",
        "gpsAccuracy": 4.5,
        "createdAt": 1789889525000,
        "updatedAt": 1789889600000
      }
    }
  ]
}
```

| property | ความหมาย |
|---|---|
| `type` | `HazardType.id` — **ค่าที่ไม่รู้จักจะกลายเป็น `other` ไม่ใช่ถูกทิ้ง** |
| `severity` | `caution` / `warning` / `danger` (ค่าที่ไม่รู้จัก → `warning`) |
| `radiusMeters` | ขอบเขตอันตราย 5–100 ม. เกินช่วงนี้จะถูกบีบเข้ากรอบตอนอ่าน |
| `isActive` | `false` = ปิดการเตือนแล้ว แต่ยังเก็บเป็นประวัติ |
| `soundId` | เสียงที่เลือกไว้ · **ไม่มีคีย์นี้ = ใช้เสียงตามระดับความอันตราย** · `"none"` = ไม่ต้องมีเสียง · id ที่เครื่องนี้ไม่มี → ตกกลับไปใช้เสียงตามระดับ ไม่ใช่เงียบ |
| `gpsAccuracy` | มีเมื่อยืนปักด้วย GPS · ไม่มีคีย์นี้ = กดปักบนแผนที่ |

**ส่งต่อกันได้:** `id` คงเดิมตอน export/import คนหนึ่งเดินสำรวจทั้งมอ แล้วคนอื่นนำเข้าไฟล์เดียวจบ
นำเข้าไฟล์เดิมซ้ำ = อัปเดตทับ ไม่ใช่จุดซ้ำ

> **ค่าที่ไม่รู้จักต้องไม่ถูกทิ้ง** — ถ้าเวอร์ชันใหม่เพิ่มประเภทอันตรายที่บิลด์นี้ไม่รู้จัก
> การเงียบทิ้งไปคือผลลัพธ์เดียวที่ทำให้มีคนเจ็บได้จริง จึงอ่านเป็น `other` แล้วเตือนต่อ

## 9. ถ้าจะแก้ต่อ อ่านตรงนี้ก่อน

- **อย่าทำให้เตือนบ่อยขึ้น** ถ้าจะแก้เกณฑ์ ให้แก้ที่ `HazardMonitor` ที่เดียว
  และเพิ่ม test ก่อนเสมอ — ไฟล์ `HazardMonitorTest.kt` มีเคส "ยืนคร่อมขอบเขตแล้วต้องไม่พูดรัว" อยู่แล้ว
- **จุดอันตรายต้องไม่เข้ากราฟ routing** ถ้าอยากให้ A* เลี่ยงจุดอันตราย ต้องทำเป็น
  "เพิ่มน้ำหนัก edge ที่ผ่านรัศมี" ใน `RouteGraphBuilder` ไม่ใช่เอาจุดไปใส่เป็น node
  (ยังไม่ได้ทำ — เพราะเลี่ยงอัตโนมัติแล้วไม่บอกเหตุผล ผู้ใช้จะงงว่าทำไมเส้นทางอ้อม)
- **อย่าเพิ่ม dialog เตือน** นอกเหนือจาก `danger` ครั้งแรก เหตุผลอยู่ใน §4
- เพิ่มประเภทใหม่: แก้ `HazardType` → เพิ่ม string ใน `strings.xml` → เพิ่มใน `Messages.kt`
  (`labelRes` เป็น `when` แบบไม่มี `else` คอมไพเลอร์จะฟ้องเองถ้าลืม)
- เพิ่มฟิลด์ใหม่: `HazardPoint` → `HazardPointEntity` (+ migration ใหม่ DB version +1)
  → `HazardGeoJson` ทั้ง write และ parse → ตารางใน §6 → test ใน `HazardGeoJsonTest`
- เสียงพูด: อย่าเปลี่ยนไปใช้ TTS ที่ต้องต่อเน็ต แอปนี้ต้องทำงานในโหมดเครื่องบิน
- **เสียงเตือนต้องดังตอนเดียวกับที่พูดเท่านั้น** ห้ามมีเงื่อนไขของตัวเอง ห้ามดังตอนที่ไม่พูด
  ทั้งสองอย่างออกจาก `announce()` ใน `MapViewModel` ที่เดียว ซึ่งเรียกจาก transition ของ monitor
- เพิ่มเสียงที่มากับแอป: เพิ่มใน `BundledHazardSound` → gen ไฟล์ด้วย `tools/make_alert_sounds.py`
  → เพิ่ม `rawResId` (`core/sound/`) และ `labelRes` (`ui/common/Messages.kt`)
  ทั้งสองเป็น `when` ไม่มี `else` คอมไพเลอร์จะฟ้องเองถ้าลืม
- **เสียงที่หาไม่เจอต้องตกกลับ ไม่ใช่เงียบ** ไฟล์ที่แชร์กันพก `soundId` ไปด้วยแต่ไม่ได้พกไฟล์เสียง
  กรณีนี้เป็นเรื่องปกติของการส่งต่อ ไม่ใช่ error — `HazardSoundTest` คุมกติกานี้ไว้
