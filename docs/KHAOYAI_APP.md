## 1. โปรเจกต์นี้คืออะไร

ตัวจริงคือ **แอปเส้นทางศึกษาธรรมชาติ อุทยานแห่งชาติเขาใหญ่** สำหรับนักท่องเที่ยว
ทุกอย่างที่ทำก่อนหน้านี้ (แผนที่ออฟไลน์ นำทางเดินเท้า เดินเก็บเส้นทาง จุดอันตราย ฯลฯ)
กลายเป็น **"ระบบนำทาง"** ซึ่งเป็นปลายทางหนึ่ง (`ky/navigation`) ของแอปนี้

```
เปิดแอป ─ (จำการเข้าสู่ระบบไว้) ─┬─ ยังไม่เข้า → หน้าเข้าสู่ระบบ
                                   ├─ ผู้ใช้     → 5 แท็บ: หน้าแรก · เส้นทาง · ธรรมชาติ · ข่าวสาร · ฉัน
                                   └─ admin     → แผงผู้ดูแล (ดูแบบผู้ใช้ได้)

หน้าเส้นทาง ─ อยู่ในเขต? ─ ใช่ → "เริ่มเดินเส้นทาง" → แผนที่ + จุดสื่อความหมายเด้งเมื่อเดินถึง
                         └ ไม่ → ล็อกไว้ + บอกระยะ + "นำทางไปจุดเริ่มต้น (Google Maps)"
```

### 2.2 การเดินเส้นทาง (สิ่งที่ผู้ใช้ขอเป็นพิเศษ)
- ห่างเส้นทางไม่เกิน **ค่าชดเชย (ค่าเริ่ม 10 ม.)** → หมุดสีฟ้าวาด**บนเส้นทาง** แต่แถบบนจอยังบอกระยะห่างจริงและ ± GPS
- เกิน **2.5 เท่า (25 ม.)** → สั่น + พูด "ออกนอกเส้นทางแล้ว" + แถบแดง **ครั้งเดียว** · กลับเข้ามาภายใน **1.5 เท่า (15 ม.)** ถึงนับว่ากลับแล้ว (กันกระพริบ)
- เส้นทางสาธิต มจพ. มีเส้นจริงตามทางเดินในวิทยาเขต 3.3 กม. (คำนวณจาก `paths.geojson`) ลองเดินได้เลย
- เส้นทางจริงเริ่มได้เฉพาะในเวลาเปิด (08:00–14:00 · เส้น 6 ถึง 10:00 และปิด 1 ก.ค.–31 ส.ค.) และอยู่ในรัศมี 1 กม.

## 4. กติกาที่ตั้งไว้

1. **เส้นทางจริงต้องอยู่ในเขตถึงจะเริ่มได้** (`data/khaoyai/TrailAccess.kt`) — วัดระยะถึง**เส้นทั้งเส้น** (ไม่ใช่แค่จุดเริ่ม) ถ้าไม่มีเส้นวัดถึงจุดเริ่ม
   รัศมีตั้งต่อเส้นได้ในหน้าผู้ดูแล (ค่าเริ่ม 1 กม.) · ไม่มี GPS = ยังไม่ตัดสิน (ไม่ใช่ปฏิเสธ) · เส้นที่ไม่มีพิกัดเลย = ไม่ล็อก
   **มีแค่เส้นทางสาธิตเส้นเดียวที่ `demoUnlocked`** — test บังคับไว้ ถ้าเปิดให้เส้นจริง คนในกรุงเทพฯ จะ "เดิน" เขาใหญ่ได้
2. **นำทางไปจุดเริ่มเปิด Google Maps ผ่านลิงก์** (`https://www.google.com/maps/dir/?api=1…`) — แอปเราไม่ได้ต่อเน็ตเอง (กฎข้อ 3)
   ไม่มี Google Maps ก็เปิดในเบราว์เซอร์
3. **จุดสื่อความหมายเด้งครั้งเดียวต่อการเดินหนึ่งรอบ** (`navigation/StationMonitor.kt`) — ไม่เด้งตอน fix แย่กว่า 30 ม. (กลัวเด้งผิดจุด)
   เด้งทีละอันไม่ซ้อนกัน · แตะหมุดบนแผนที่เปิดดูซ้ำได้เสมอ · เปลี่ยนเส้น/เริ่มใหม่ = นับใหม่
   (ต่างจากจุดอันตรายที่ต้องเตือนซ้ำเมื่อกลับเข้ามาใหม่ — ดู `HAZARDS.md` อย่าเอาไปรวมกัน)
4. **การแก้ไขของผู้ดูแลเก็บลงเครื่องแล้ว** (`filesDir/khaoyai/content.json` เขียนไฟล์ชั่วคราวแล้ว rename กันไฟล์พัง)
   รูปที่ผู้ดูแลเลือกถูกย่อ ≤1280 px แล้วคัดลอกเข้า `filesDir/khaoyai/photos/` (ใช้ photo picker ของระบบ ไม่ต้องขอสิทธิ์)
   **ข้อควรรู้:** ถ้าแก้ไขแล้วครั้งหนึ่ง ไฟล์ตัวอย่างใหม่ในแอปเวอร์ชันถัดไปจะ**ไม่ทับ**ของที่แก้ไว้ จนกว่าจะกด "คืนค่าข้อมูลตัวอย่าง"
5. **SOS เก็บในเครื่องเดียวกันเท่านั้น** (Room ตาราง `sos_report`, DB v9) — ผู้ดูแลในเครื่องเดียวกันถึงจะเห็น
   หน้า SOS บอกผู้ใช้ตรง ๆ และวาง**ปุ่มโทร**ไว้บนสุด + ปุ่ม "ส่งต่อทาง SMS / แชท" (ข้อความมีพิกัด ± ความแม่น + ลิงก์แผนที่)
   **ห้ามเอาคำเตือนนี้ออกจนกว่าจะมีเซิร์ฟเวอร์จริง** — ถ้าคนรอความช่วยเหลือจากปุ่มที่ไม่ได้ส่งไปไหน อันตรายถึงชีวิต
6. **แผนที่สวยขึ้นด้วยการแต่งสีตอนรัน** (`map/ForestMapLook.kt`) — ป่าเขียวขึ้น น้ำฟ้าขึ้น ทางเดินเป็นสีน้ำตาล
   แก้แค่ paint ของ layer ที่มีอยู่แล้วใน style liberty ไม่ดาวน์โหลดอะไรเพิ่ม ไม่ติดลิขสิทธิ์
7. ข้อความหน้าจอทุกตัวอยู่ `strings.xml` · เนื้อหา (เส้นทาง ข่าว สัตว์) อยู่ JSON เหมือน `pois.geojson`

## 7. ฟีเจอร์ที่แนะนำต่อ (ยังไม่ได้ทำ)

1. **ผูกเส้นที่เดินเก็บเข้ากับเส้นทาง** — ในฟอร์มผู้ดูแล เลือก track จาก "เดินเก็บเส้นทาง" มาเป็น `path` ของ Trail
2. **เสียงบรรยายตอนเดินถึงจุด** — ใช้ `SpeechAnnouncer` (TTS ในเครื่อง) อ่านชื่อจุด (ระวังซ้อนกับเสียงเตือนจุดอันตราย)
3. **สะสมตราเมื่อเดินครบเส้น** — ใช้ข้อมูล `route_history` + `StationMonitor` นับว่าผ่านกี่จุด
4. **บันทึกการพบสัตว์** — ปุ่ม "เจอแล้ว" ในหน้าสัตว์ เก็บพิกัด+เวลา (แยกจากระบบค่าที่วัดได้ตามกฎข้อ 9)
5. **แบบทดสอบท้ายเส้นทาง** สำหรับนักเรียน · **ภาษาอังกฤษ** (`values-en/`) สำหรับนักท่องเที่ยวต่างชาติ

## 8. วิธีทดสอบเองเมื่อพร้อม

```powershell
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
./gradlew.bat assembleDebug ; ./gradlew.bat test ; ./gradlew.bat installDebug
```

1. เปิดแอป → **เข้าสู่ระบบ** ทันที → หน้าแรกมีรูปจริง · ปิดแอปแล้วเปิดใหม่ → ต้อง**ไม่**ถามเข้าสู่ระบบอีก
2. แท็บเส้นทาง → **เส้นทางสาธิต มจพ.** → ปุ่ม "เริ่มเดินเส้นทาง" กดได้ → แผนที่มีหมุดเลข 1–5 + แถบ "กำลังเดิน"
   เดินไปจุดไหนในวิทยาเขต (≤30 ม.) → สั่น + การ์ดเด้ง · แตะหมุด → เปิดการ์ดซ้ำได้ · "จบเส้นทาง" → หมุดหาย
3. แท็บเส้นทาง → เส้นทางเขาใหญ่ใด ๆ (ไม่ได้อยู่เขาใหญ่) → ต้องขึ้น **"คุณยังอยู่นอกเขตเส้นทาง ห่าง xx กม."** + ปุ่มเริ่มกดไม่ได้ + ปุ่ม Google Maps
4. ในแผนที่ (ผู้ใช้) → กดค้าง = ไม่มีอะไร · แตะจุด → ไม่มีปุ่มแก้ไข · ตั้งค่า → ไม่มีเมนูผู้ดูแล
5. SOS (หน้าแรกมุมขวาบน) → เลือกเหตุ → ส่ง → "ส่งต่อทาง SMS / แชท" ข้อความมีพิกัด
6. ออกจากระบบ → `admin` → แผงผู้ดูแล → การ์ด SOS แดง "มีเรื่องใหม่ 1 เรื่อง" → แผนที่มีหมุดแดง → รับเรื่อง → เหลือง → เสร็จสิ้น → เขียว
7. แผงผู้ดูแล → แก้เส้นทางสาธิต → เพิ่มจุดสื่อความหมาย → "ใช้ตำแหน่งที่ยืนอยู่" → เลือกรูป → บันทึก → ปิดแอปเปิดใหม่ → ต้องยังอยู่
8. แผงผู้ดูแล → เครื่องมือแผนที่ → เดินเก็บเส้นทาง / จุดอันตราย → เปิดตรงหน้านั้น · กดย้อนกลับมาแผงผู้ดูแล
