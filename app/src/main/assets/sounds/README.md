# assets/sounds — เสียงเตือนจุดอันตรายที่ฝังมากับแอป

**วางไฟล์เสียงลงในโฟลเดอร์นี้ แล้ว build ใหม่ — เสียงจะโผล่ในแอปเอง ไม่ต้องแก้โค้ดสักบรรทัด**

```
app/src/main/assets/sounds/
├── README.md
├── siren.mp3            → ขึ้นในรายการเลือกเสียงชื่อ "siren"
└── default_danger.mp3   → กลายเป็นเสียงเริ่มต้นของจุด "อันตรายมาก" ทุกจุด
```

## ต่างจาก "นำเข้าเสียงจากเครื่อง" ยังไง

| | วางไว้ในโฟลเดอร์นี้ | นำเข้าจากในแอป |
|---|---|---|
| อยู่ที่ไหน | **ในตัว APK** ติดไปกับแอป | เครื่องใครเครื่องมัน |
| ทุกคนที่ลงแอปได้ยินไหม | **ได้ยินเหมือนกันหมด** | เฉพาะคนที่นำเข้าเอง |
| แชร์ `hazards.geojson` แล้วเสียงติดไปด้วยไหม | **ติดไป** (id เหมือนกันทุกเครื่องที่ใช้ build เดียวกัน) | ไม่ติด — ตกกลับไปใช้เสียงตามระดับความอันตราย |
| เพิ่มยังไง | วางไฟล์ แล้ว build | กดปุ่มในหน้าปักจุด |

## กติกา

**นามสกุลที่รับ:** `.mp3` · `.ogg` · `.wav` · `.m4a` · `.aac` · `.opus`

จำกัดไว้เท่านี้เพราะ Android ไม่บีบอัดไฟล์พวกนี้ตอนแพ็กลง APK แอปจึงเปิดอ่านตรง ๆ ได้
ไฟล์นามสกุลอื่นจะถูก **ข้ามไปเงียบ ๆ** ดีกว่าเอามาโชว์ในรายการแล้วกดเล่นไม่ออกตอนอยู่ริมถนน

**ควรสั้น ไม่เกิน 2–3 วินาที** เสียงนี้ดัง **นำหน้า** ประโยคที่พูดว่าอันตรายอะไรอยู่ข้างหน้ากี่เมตร
ถ้าเสียงยาว ประโยคจะมาช้าจนคนเดินผ่านจุดนั้นไปแล้ว

> ไฟล์ที่นำเข้าจากในแอปถูกบังคับไม่เกิน 10 วินาที แต่ไฟล์ในโฟลเดอร์นี้ **ไม่มีอะไรบังคับ**
> เพราะเป็นของที่คนทำแอปใส่เอง ถ้าใส่เพลงยาว 3 นาที มันจะเล่น 3 นาทีจริง ๆ

**ชื่อไฟล์คือชื่อที่ผู้ใช้เห็น** (ตัดนามสกุลออก) ตั้งชื่อให้คนอ่านรู้เรื่อง เช่น
`เสียงออด.mp3` ดีกว่า `alert_v2_final.mp3`

## ชื่อพิเศษ: แทนเสียงเริ่มต้นไปเลย

จุดอันตรายที่คนปักไม่ได้เลือกเสียงเอง จะใช้เสียงตามระดับความอันตราย
ปกติคือเสียงบี๊บที่ gen มากับแอป แต่ถ้ามีไฟล์ชื่อตรงกับข้างล่างนี้ **ไฟล์นี้จะถูกใช้แทน**

| ชื่อไฟล์ (นามสกุลอะไรก็ได้) | แทนเสียงเริ่มต้นของระดับ |
|---|---|
| `default_caution.*` | ควรระวัง |
| `default_warning.*` | อันตราย |
| `default_danger.*` | อันตรายมาก |

ไม่ต้องตั้งค่าอะไรเพิ่ม ไม่ต้องไปกดในแอป วางไฟล์แล้ว build ก็เปลี่ยนทั้งระบบ
ถ้าไม่มีไฟล์พวกนี้ ก็ใช้เสียงที่ gen มาตามเดิม — เสียงที่ gen มาจึงหายไปไม่ได้
