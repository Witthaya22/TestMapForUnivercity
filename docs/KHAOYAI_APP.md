## 1. โปรเจกต์นี้เปลี่ยนเป็นอะไร

ตัวจริงคือ **แอปเส้นทางศึกษาธรรมชาติ อุทยานแห่งชาติเขาใหญ่** สำหรับนักท่องเที่ยว
ทุกอย่างที่ทำมาก่อนหน้านี้ (แผนที่ออฟไลน์ นำทางเดินเท้าด้วย GPS เดินเก็บเส้นทาง จุดอันตราย ฯลฯ)
กลายเป็น **ฟีเจอร์หนึ่ง** ของแอปนี้ ชื่อเรียกในโค้ดคือ **"ระบบนำทาง" (navigation feature)**

```
เปิดแอป → หน้าเข้าสู่ระบบ ─┬─ (ชื่อผู้ใช้ว่าง/อะไรก็ได้) → แอปผู้ใช้ 5 แท็บ
                           └─ (พิมพ์ admin)               → หน้าผู้ดูแลระบบ
แอปผู้ใช้: หน้าแรก · เส้นทาง · ธรรมชาติ (สัตว์/พืช) · ข่าวสาร · ฉัน
           └─ ปุ่ม "เปิดแผนที่นำทาง" / "เริ่มนำทาง" → ระบบนำทางเดิมทั้งก้อน (AppNavHost)
```

**ยังไม่ได้รันบนเครื่อง** — ผู้ใช้สั่งให้เขียนโค้ดไว้ก่อน ตรวจแค่ `assembleDebug` ผ่าน + `test` เขียว

## 3. กติกาที่ตั้งไว้ (อย่าเปลี่ยนโดยไม่รู้ตัว)

1. **เข้าสู่ระบบยังไม่มีฐานข้อมูล** — กดเข้าได้เลยไม่ต้องกรอก · ชื่อผู้ใช้ `admin` (ตัวใหญ่/เล็กก็ได้ เว้นวรรคหน้าหลังก็ได้)
   → หน้าผู้ดูแล · รหัสผ่านไม่ถูกตรวจเลย · มีคอมเมนต์ `shortcut:` ใน `KhaoYaiSession.kt`
   **ห้ามปล่อยขึ้น Play Store ทั้งแบบนี้** ใครพิมพ์ admin ก็เป็นผู้ดูแล
2. **ที่หน้าเข้าสู่ระบบไม่ได้บอกว่าพิมพ์ admin ได้** — ตั้งใจ บอกแค่ "กดเข้าได้เลย"
3. **การแก้ไขจากหน้าผู้ดูแลหายเมื่อปิดแอป** (เก็บในหน่วยความจำ) — หน้าผู้ดูแลมีป้ายบอกตรง ๆ
4. **ข้อมูลเนื้อหา (ชื่อเส้นทาง/ข่าว/สัตว์) อยู่ใน JSON ไม่ใช่ `strings.xml`** — เป็นข้อมูลแบบเดียวกับ
   `pois.geojson` ที่ผู้ดูแลแก้ได้ ส่วนข้อความของหน้าจอทุกตัวยังอยู่ใน `strings.xml` ตามกฎข้อ 8
5. **รูปภาพทั้งหมดวาดเอง** (vector) + อีโมจิของระบบ — ไม่มีรูปจากเว็บเลย จึงไม่มีเรื่องลิขสิทธิ์
   และไม่ทำให้ APK ใหญ่ ถ้าจะใส่ภาพถ่ายจริง ดู §6 ข้อ 4
6. **ระบบนำทางเดิมไม่ถูกแก้แม้แต่บรรทัดเดียว** — แค่ย้ายจาก `MainActivity` ไปเป็นปลายทาง `ky/navigation`
   มี NavHost ของตัวเอง กดย้อนจากหน้าแรกของมัน (แผนที่) = กลับมาแอปหลัก
7. ทุกเส้นทาง/ข่าวในแอปแสดงป้าย **"ข้อมูลในแอปตอนนี้เป็นข้อมูลตัวอย่าง"** — เอาออกเมื่อข้อมูลจริงมาแล้ว

## 4. ข้อมูลตัวอย่างมาจากไหน (ต้องตรวจก่อนใช้จริง)

- เขาใหญ่มีเส้นทางศึกษาธรรมชาติระยะสั้น **7 เส้นทาง** ยาวตั้งแต่ราว 1.2–8 กม. บางเส้นต้องมีเจ้าหน้าที่นำ
  ([The Standard](https://thestandard.co/life/hiking-trail-at-khao-yai-national-park/))
- ผากล้วยไม้–น้ำตกเหวสุวัต 3.4 กม. ([Thai Post](https://www.thaipost.net/tac/97901/)) · หนองผักชี ราว 3.3 กม.
- **ที่ยังเดาอยู่:** ชื่อ 7 เส้นทางในไฟล์เป็นชุดที่รู้จักกันทั่วไป **ยังไม่ได้ยืนยันกับรายชื่อทางการ**
  ระยะทาง/เวลาของ เหวนรก ผาเดียวดาย และเส้นทางยาว 8 กม. เป็นค่าประมาณ · ข่าวทั้ง 5 ข่าวแต่งขึ้นเป็นตัวอย่าง
- ข้อมูลอุทยาน (พ.ศ. 2505 แห่งแรกของไทย · 4 จังหวัด · มรดกโลก พ.ศ. 2548 · เขาร่ม 1,351 ม.) เป็นข้อมูลทั่วไปที่เป็นที่รู้จัก
- สถานภาพ IUCN ของสัตว์ใส่ตามที่รู้ (ช้าง EN · นกกก VU · ชะนีมือขาว EN · กวางป่า VU · เก้ง LC · ลิงกังเหนือ VU)
- เบอร์ฉุกเฉินใส่เฉพาะเบอร์ระดับประเทศ (1669 · 1155 · 1362) **ยังไม่ได้ใส่เบอร์ที่ทำการอุทยาน** ต้องหามาใส่

ข้อความที่ผู้ใช้พิมพ์มาถูกตัดจบที่ *"…แต่เราเดินทางเท้าทั้งหมดจะมี 7"* — เข้าใจว่าหมายถึง 7 เส้นทาง
**ถ้าไม่ใช่ ให้ถามผู้ใช้ก่อนทำต่อ**

## 6. ฟีเจอร์ที่แนะนำสำหรับแอปเส้นทางศึกษาธรรมชาติ

เรียงจาก "เข้ากับของที่มีแล้ว ทำง่าย" ไป "ต้องตัดสินใจก่อน":

1. **จุดสื่อความหมายบนแผนที่** — เดินถึงหลักที่ 3 แล้วแอปเด้งเรื่องของหลักนั้น (ใช้กลไกเดียวกับ `HazardMonitor`
   แต่เป็นข้อมูลความรู้ ไม่ใช่คำเตือน) · ตอนนี้มีรายชื่อจุดในหน้ารายละเอียดเส้นทางแล้ว ขาดพิกัด
2. **สมุดสะสมแสตมป์ / เหรียญ** — เดินครบเส้น = ได้ตราประจำเส้น · ใช้ข้อมูลจาก `route_history` ที่บันทึกอยู่แล้วแต่ยังไม่มีหน้าแสดง
3. **บันทึกการพบสัตว์ (sighting log)** — กดปุ่ม "เจอแล้ว" ในหน้าสัตว์ เก็บพิกัด+เวลา (ระวังกฎข้อ 9:
   ต้องแยกจากระบบค่าที่วัดได้) · อาจเปิดให้ผู้ดูแลเห็นแผนที่ความร้อนว่าเจอช้างตรงไหนบ่อย
4. **ภาพถ่ายจริงของสัตว์/พืช** — ใช้ภาพที่อุทยานอนุญาต หรือ Wikimedia Commons ที่เป็น CC0/CC BY
   (ต้องเก็บชื่อผู้ถ่ายและ license ไว้ในข้อมูล แล้วแสดงใต้ภาพ) ใส่ฟิลด์ `imageAsset` + `imageCredit`
5. **สถานะเส้นทางวันนี้** — เปิด/ปิด ฤดูทาก น้ำหลาก (มีฟิลด์ `isOpen` แล้ว ต้องมีที่มาของข้อมูลสด ⇒ ต้องมีเน็ต)
6. **ปุ่ม SOS ส่งพิกัดตัวเอง** — SMS พิกัดล่าสุดไปเบอร์อุทยาน (SMS ใช้ได้แม้ไม่มีเน็ตมือถือ)
7. **แบบทดสอบท้ายเส้นทาง** — 3–5 ข้อจากจุดสื่อความหมาย เหมาะกับนักเรียนที่มาทัศนศึกษา
8. **เสียงบรรยายระหว่างเดิน** — ใช้ `SpeechAnnouncer` (TTS ในเครื่อง) ที่มีอยู่แล้ว อ่านเรื่องของจุดที่เดินถึง
9. **โหมดภาษาอังกฤษ** — นักท่องเที่ยวต่างชาติที่เขาใหญ่มีมาก · ต้องแยก `values-en/strings.xml` + เนื้อหา 2 ภาษาใน JSON

## 7. วิธีทดสอบเองเมื่อพร้อม

```powershell
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
./gradlew.bat assembleDebug ; ./gradlew.bat test ; ./gradlew.bat installDebug
```

1. เปิดแอป → กด **เข้าสู่ระบบ** ทันที (ไม่ต้องกรอก) → ต้องเข้าหน้าแรก ทักว่า "สวัสดี, นักท่องเที่ยว"
2. แท็บ **ฉัน** → ออกจากระบบ → พิมพ์ `Admin` → เข้าสู่ระบบ → ต้องเข้า **แผงผู้ดูแลระบบ**
3. ผู้ดูแล: เพิ่มเส้นทางใหม่ (เว้นชื่อไว้ → ปุ่มบันทึกต้องกดไม่ได้) → บันทึก → **ดูแอปแบบผู้ใช้** → แท็บเส้นทางต้องมีเส้นใหม่
4. ผู้ดูแล: ลบข่าว → ดูแอปแบบผู้ใช้ → ข่าวหายจากหน้าแรกและแท็บข่าว
5. หน้ารายละเอียดเส้นทาง → **เริ่มนำทาง** → เข้าระบบนำทางเดิม (ครั้งแรกจะเป็นหน้าดาวน์โหลดแผนที่) → กดย้อน → กลับมาหน้าเส้นทาง
6. หมุนจอระหว่างกรอกฟอร์มผู้ดูแล → ข้อความที่พิมพ์ต้องไม่หาย
7. เปิดโหมดเครื่องบินแล้วทำข้อ 1–5 ซ้ำ (ทุกหน้าใหม่ไม่ต้องใช้เน็ต)
