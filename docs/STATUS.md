## 4. ตอนนี้แอปทำอะไรได้บ้าง

### หน้าแผนที่หลัก
- นำทางเดินตามถนน/ทางเดินจริง ออฟไลน์
- **บอกค่าความแม่นยำ GPS ตลอดเวลา** (`± x.x ม.` + แม่นยำดี/พอใช้/ยังไม่แม่น)
- เตือนจุดอันตรายด้วยแบนเนอร์ + เสียง + เสียงพูด
- **ตอนนำทาง หมุดถูกดึงไปอยู่บนเส้นทาง** ถ้าอยู่ใกล้เส้นพอ (ดู `ACCURACY.md` A9)
- **เตือนบนจอ** เมื่อ GPS คลาดเคลื่อนมาก หรือออกนอกเส้นทาง

### 4 ระบบเก็บพิกัด (ตั้งใจแยกกัน อย่ารวม)

| ระบบ | ได้อะไร | เข้ากราฟนำทางไหม | เอกสาร |
|---|---|---|---|
| โหมดสำรวจพิกัด (`ui/survey/`) | จุดสถานที่ (POI) | เป็นจุดหมายได้ | `SCREENS.md` §5 |
| เก็บพิกัด GPS (`ui/gpslog/`) | ค่าที่วัดได้ล้วน ๆ | **ไม่** | `GPS_LOGGING.md` |
| **เดินเก็บเส้นทาง (`ui/pathlog/`)** | เส้นทาง | **ได้ ถ้าเปิดสวิตช์ทีละเส้น** | `PATH_LOGGING.md` |
| จุดอันตราย (`ui/hazard/`) | จุด + รัศมี + เสียง | ไม่ | `HAZARDS.md` |

**เก็บพิกัด GPS** กับ **เดินเก็บเส้นทาง** มี 2 โหมดคู่กัน: มีแผนที่ (เห็นภาพรวม) / ตัวเลขล้วน (เปิดเร็ว กินแบตน้อย)
โหมดสำรวจ POI กับจุดอันตรายมีหน้าเดียว — หน้าจอทั้งหมดดูที่ `docs/SCREENS.md`

### เสียงเตือนจุดอันตราย
- **เสียงนำ** → แล้วค่อย **พูด** (คำสั้นซ้ำ 3 ครั้ง เช่น `เขตถนนอันตราย, เขตถนนอันตราย, เขตถนนอันตราย`)
- เพิ่มเสียงเองได้ 2 ทาง: นำเข้าในแอป (เฉพาะเครื่องตัวเอง) / วางใน `assets/sounds/` (ติดไปกับแอปทุกเครื่อง)
- ลองฟังได้ทั้งเสียงและคำพูด ที่ **ตั้งค่า → การเตือนจุดอันตราย → เสียงเตือน**

## 6. ถ้าพังต้องทำยังไง

### แอปรันไม่ได้ / Android Studio ฟ้อง Activity ไม่มีอยู่

```
Activity class {com.example.testmapforunivercity/...MainActivity} does not exist
```

**ไม่ใช่บั๊กของโค้ด** — เป็น cache ค้างของ Android Studio จากตอนสร้างโปรเจกต์จากเทมเพลต

1. ปิด Android Studio ให้สนิท
2. `rm .idea/workspace.xml`
3. เปิดใหม่ รอ Gradle sync แล้วกด Run

หรือข้าม IDE ไปเลย: `./gradlew.bat installDebug`

### build พังที่ `compileDebugJavaWithJavac` เรื่อง `jlink`

Gradle ไปหยิบ JRE ของ VS Code ที่ไม่มี `jlink` มาใช้ **ต้องตั้ง JAVA_HOME ทุกครั้งก่อน build**

```powershell
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
./gradlew.bat assembleDebug
```

ถ้ายังพัง daemon เก่าอาจค้างอยู่ → `./gradlew.bat --stop` แล้วสั่งใหม่

### อยากย้อนกลับไปก่อนหน้านี้

```bash
git log --oneline                  # หา commit ที่ต้องการ
git revert <commit>                # ย้อนทีละ commit แบบไม่ทำลายประวัติ
```

commit แยกเป็นส่วน ๆ (ฟีเจอร์ / test / เอกสาร) จึง revert เฉพาะส่วนที่พังได้ โดยไม่กระทบส่วนอื่น

### ฐานข้อมูลพัง / อยากเริ่มใหม่

ถอนแอปแล้วติดตั้งใหม่ (`adb uninstall th.ac.kmutnb.prachin.map`) — **แต่ข้อมูลที่เก็บไว้จะหายหมด
ส่งออกไฟล์เก็บไว้ก่อนเสมอ** Room เป็น version 8 และมี migration จริงทุกขั้น ห้ามใช้ destructive migration
